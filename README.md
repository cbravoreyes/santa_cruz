# Santa Cruz: historia, cultura e identidad

Primera versión funcional para GitHub Pages.

## Publicar en GitHub Pages

1. Cree un repositorio nuevo en GitHub.
2. Suba todo el contenido de esta carpeta manteniendo la estructura.
3. En GitHub vaya a **Settings → Pages**.
4. En **Build and deployment**, seleccione **Deploy from a branch**.
5. Elija la rama `main` y la carpeta `/ (root)`.
6. Guarde. GitHub generará la dirección pública del sitio.

## Estructura

- `index.html`: contenido principal.
- `css/estilos.css`: diseño responsivo.
- `js/app.js`: navegación, pestañas, cuestionario y sopa de letras.
- `img/`: carpeta preparada para imágenes futuras.
